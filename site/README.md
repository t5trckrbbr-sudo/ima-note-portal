## 2026-11-23 배치 기준 및 복원 항목

- **수신 화면 순서 유지**: `실적에서 전망으로` 바로 다음에 2027 수신환경·베어 플랫 전망과 단기 수익률곡선 패널을 배치하고, 회사별 인라인 드릴다운 분해표·머니무브 안전성 렌즈를 거쳐 **NIM 계산기는 맨 아래**에 둡니다.
- **OpenDART 2026.3Q 기준**. 발행어음 57.24조·IMA 4.09조의 합산 61.33조를 사용합니다. 2027년 기본 전망은 85조(어음 80 + IMA 5)이며 메리츠 연말 4조·평잔 2조 가정을 반영합니다.
- **IMA 구NCR 비교**: `#ima-maturity`에서 취득 자산 위험률별 발행어음·IMA 구NCR 두 곡선과 교차점을 비교합니다. 구NCR에도 위험액 50% 감경을 반영하고, 5% 전액 순자본 감소·신규액 전부 감경 한도 내라는 비교 가정과 법령 요건·폐쇄형 예외를 함께 표시합니다. 관련 Q&A `guide-ima-old-ncr-capital`을 추가해 기본 가이드는 18건입니다.
- **기존 잔액의 의무비율 상승분 자동 적용**. 기회비용 계산은 신규 수신 × 20%와 기존 기준 잔액 × 10%p를 합산합니다. 61.33조 → 85조의 전체 기본 가정은 연 1,630.05억 원, 상한 활용 시 연 1,141.035억 원입니다.
- **전 사이트 의식의 흐름 연결성 고도화(`site/public/xray.js`)**:
  - 깔끔한 미세 점선 밑줄·호버 스타일로 KPI 카드, SVG 시계열 차트 포인트(`2021~2027E`, 가계자산 분기·연간 추이, `MR=MC Q*`), 테이블 수치, `산식·근거 열기`를 클릭하면 화면 이탈 없이 우측 슬라이드 **「데이터 X-Ray · 연관 질문 인스펙터」**가 열려 산식 분해·원천 통계코드·관련 Q&A 핵심 요약·다음 맥락 점프를 제공합니다.
  - NIM 시뮬레이터(`#nim-lab`)의 9대 증권사명까지 회사별 통합 X-Ray(NIM 수익 vs 모험자본 기회비용 vs 실효금리 vs 전사 ROE)로 연동하고, 상단 바에 최근 탐색 경로와 `↩ 이전 맥락` 복귀 버튼을 담은 **의식의 흐름 발자국(Thought-Trail) 브레드크럼**을 적용했습니다.
- **연쇄 드릴다운 & 동기화 탐색(`site/public/curiosity.js`)**:
  - `#funding`: 9사 전원 인가(`26.09` 삼성 8호·메리츠 9호 어음, `26.03` NH IMA 3호) 기반 회사별 행 클릭 시 인가/전제 → 자본비율 격차·조달수단별 실효금리 → 전사 ROE가 즉시 펼쳐지며, 머니무브 패널 제목 아래 **`광의통화 M2` 왼쪽에 `전체 가계자산(16,641.3조 원)` 점프 카드**를 배치해 별도 탭(`#household-wealth`)과 유기적으로 연결했습니다.
  - `#household-wealth` (`가계자산 · 5개국 비교` 신설): 수신의 근원인 한국 가계자산을 **실물(`10,433.7조`) vs 금융 → 5대 금융부문(`6,930.2조`) → 자산 17개 세부 항목·부채 참고 1개** 3단계로 분해하고, 분기(`2019.4Q~2026.2Q`)·연간(`2020~2025`) 시계열, **비금융법인(`S11`) 단기 유동성(`1,135.9조`) & 가계금융복지조사 순자산 5분위 분포(상위 20% 집중도)**, **한국·미국·영국·일본·중국(+유로존) 5개국 GDP·가계자산 구성비 비교**를 한 화면에서 탐색합니다.
  - `#ib-funding`: 증권사 선택 칩·차입 포트폴리오·수단별 실효금리·전사 수익성(ROE) 대조표가 실시간 동기화됩니다.
  - `#invest`는 AAA 은행채 3년 평가수익률 4.113%(2026-11-13) 비교와 모험자본 기회비용 계산을 제공합니다. 인정자산 수요·공급 패널은 금융위 분기말 인정 잔액과 중기부 벤처투자 누적액을 표시하고 성장기업 신규 자금을 겨냥한 인정 범위 확대를 설명합니다.
  - `#funding`의 베어 플랫 패널은 국고채 3년–1년 스프레드 변화, 당사 어음 한도 사용률과 IMA 만기를 연결해 조달·운용·만기 매칭 선택과 하반기 조건을 보여줍니다.
  - 삼성 별도 목표액은 기본 전망에 배정하지 않으며, 선택 시나리오를 NIM 및 비용과 연동합니다.
  - `#pnl` **발행어음·IMA 9대 고유 규제 · 금감원 보고 주기 · 복구기한 · 법적 페널티 총람(`#reg-compliance-matrix`)**: 원화 유동성비율(`1·3개월 ≥100%`)·외화 유동성비율(`≥80%`), 레버리지 차감 특례, 신NCR 위험액, 자기신탁 구분관리·자전거래 금지, 금소법 설명의무 및 조항별 보고기한·유예기간·제재 수위를 법적 근거와 함께 정리했습니다.

## 질문을 올린 뒤 업데이트하는 방법

사이트에서 질문을 등록하고 ChatGPT 대화에서 **“사이트 Q&A 업데이트해줘”**라고 요청하면 새 질문에 답하고 기존 답변 전체도 다시 검토합니다. 검토일·근거·변경 내용·이력을 남기며 근거가 부족하면 ‘추가 확인 필요’로 표시합니다. 자동 일정으로 실행하지 않습니다.

운영 절차는 [REVIEW_WORKFLOW.md](./REVIEW_WORKFLOW.md)를 따릅니다. `site/`에서 `npm run review:prepare`로 전체 질문을 수집하고, 검토 후 `review:apply`·검사·테스트·빌드·`review:verify`를 거쳐 배포합니다. 초기 검토 기록은 비어 있으며 기존 답변을 새로 검증한 것으로 표시하지 않습니다. 사용자 D1 데이터는 보존합니다.
